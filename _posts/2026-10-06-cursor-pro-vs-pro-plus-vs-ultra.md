Cursor is the AI code editor many developers now use daily. Choosing a paid tier comes down to one question: **how much model usage will you burn each month?**

## The three tiers

| Plan | Official price | Included third-party model usage | Best for |
|---|---|---|---|
| Pro | $20/mo | about $20 | Everyday coding, occasional agent use |
| Pro+ | $60/mo | about $70 | Heavy daily agent use |
| Ultra | $200/mo | about $400 | Power users, roughly 20x Pro usage |

All three include unlimited Tab completions plus agents, Bugbot and cloud agents. When included usage runs out you can keep going pay-as-you-go, with an optional spending cap.

## How to choose

- **Start with Pro** and watch a month of real usage.
- If you run out mid-month and would rather not pay overage, **Pro+** is usually cheaper.
- **Ultra** is for people whose agents run all day; most individuals do not need it.
- Yearly billing takes about 20% off.
