Claude 的三档个人会员，功能几乎一样，差别在**用量**。Pro 和 Max 都包含 Claude Code。

## 三档对比

| 套餐 | 官方月费 | 用量 | 适合谁 |
|---|---|---|---|
| Pro | $20（年付约 $17/月） | 基础用量 | 日常对话、写作、偶尔用 Claude Code |
| Max 5x | $100 | Pro 的 5 倍 | 每天写代码，用 Pro 经常触顶 |
| Max 20x | $200 | Pro 的 20 倍 | 一整天都在用，或同时开多个 Claude Code |

Max 5x 和 Max 20x 的功能一致，只是额度不同。

## “5 倍”“20 倍”是什么意思

Claude 的用量按**滚动的 5 小时窗口**计算，倍数指每个窗口内能用的量。除此之外还有**每周的总上限**，所以它不是“什么都多 20 倍”。重度使用时，两个限制都会碰到。

## 选择建议

- **小项目、偶尔写代码：** Pro 就够了。
- **正常工作日里就会触顶：** 升到 Max 5x。
- **每天写好几个小时、同时跑多个会话，或者 Max 5x 的周上限也经常碰到：** 再考虑 Max 20x。

如果只是用 API 做开发，不需要网页版和 Claude Code，直接买 API 额度可能更合适：按用量付费，没有月费。
